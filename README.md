# Avito Find Home

Монитор долгосрочной аренды на Avito. Он открывает обычный видимый Chrome,
собирает объявления из поисковой выдачи, фильтрует и оценивает их, отправляет в
Telegram и осторожно открывает лучшие карточки для получения полного описания,
правил, реальной цены с ЖКУ и фотографий.

## Как это работает

1. Парсер обходит настроенные выдачи квартир и домов.
2. Отбрасывает посуточную аренду и жильё с числом комнат ниже заданного.
3. Сразу отправляет каждое новое подходящее объявление в Telegram.
4. Для объявлений с рейтингом от заданного порога открывает детальную карточку.
5. Редактирует исходное сообщение, добавляет полные параметры и отправляет
   фотографии ответом на него.
6. Ждёт случайный интервал из `collection.interval_minutes_min/max` и начинает
   следующий цикл. В текущей конфигурации это 120–180 минут.

Повторные объявления не отправляются: состояние хранится в SQLite. При капче
Chrome остаётся видимым, а в Telegram приходит служебное предупреждение.
Рекламное окно Avito про «секретные» квартиры или дома закрывается
автоматически; капча по-прежнему требует ручного прохождения.

## Фильтры и рейтинг

Все пользовательские правила находятся в [`config.yaml`](config.yaml):

- `city` — город и штатные ссылки Avito;
- `hard_filters` — минимальное число комнат и исключение посуточной аренды;
- `rating` — площадь, максимальная реальная цена, баллы и списки улиц;
- `important` — параметры верхнего информационного блока и границы цветов цены;
- `collection` — интервалы и паузы;
- `details` — порог рейтинга, лимит открываемых карточек и фотографии.

Текущая формула:

- площадь от 54 м²: `+1`;
- реальная цена до 40 000 ₽ включительно: `+1`;
- хорошая улица: `+2`;
- нейтральная улица: `+1`;
- плохая улица: `−1`;
- комиссия и возможность проживания с детьми отображаются, но баллы не меняют.

Реальная цена — аренда плюс параметр Avito «Другие ЖКУ». Пока детальная карточка
не открыта, сообщение явно сообщает, что ЖКУ ещё не учтены.

## Пример сообщения

```text
🏠 2-к. квартира, 60 м², 7/12 эт.
⭐ Рейтинг: 3/4 баллов

Важное
🔴 С детьми нельзя (на рейтинг не влияет)
🟡 Есть комиссия (на рейтинг не влияет)
🟡 Цена 38 000 ₽/месяц (ЖКУ 3 000 ₽): +1 балл
🟢 Площадь от 54 м²: +1 балл
🟢 Нейтральная улица: +1 балл

Основное
💰 Реальная цена: 38 000 ₽/месяц (ЖКУ 3 000 ₽)
📐 Площадь: 60 м²
🚪 Комнат: 2
📍 Адрес: ул. Примерная, 10
```

## Установка

Требуются Python 3.13 и Google Chrome.

```bash
python -m venv .venv
```

Linux/macOS:

```bash
. .venv/bin/activate
pip install -r requirements.txt
```

Windows:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=чат_для_средних_вариантов
TELEGRAM_TECH_CHAT_ID=чат_для_технических_уведомлений
TELEGRAM_PRIORITY_CHAT_ID=чат_для_рейтинга_3_4
TELEGRAM_TRASH_CHAT_ID=чат_для_рейтинга_0_1
```

`TELEGRAM_CHAT_ID` принимает варианты с рейтингом 2. Дополнительные чаты
необязательны: если чат лучших или слабых вариантов не указан, соответствующие
объявления отправляются в `TELEGRAM_CHAT_ID`. Технический чат получает ошибки,
капчу и итог каждого прохода: число новых и обновлённых объявлений и время
следующего запуска. Если он не указан, эти сообщения также идут в
`TELEGRAM_CHAT_ID`.

## Запуск

Один цикл:

```bash
python semi_manual_collector.py --once
```

Постоянный мониторинг:

```bash
python semi_manual_collector.py
```

Полезные режимы:

```bash
python semi_manual_collector.py --once --no-details
python semi_manual_collector.py --details-only --max-details 1
python semi_manual_collector.py --notify-only
```

При первом запуске откроется Chrome с отдельным профилем в `runtime/`. Если Avito
покажет капчу или попросит войти, сделайте это вручную в данном окне.

## Windows и автозапуск

Запустите PowerShell от обычного пользователя:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\windows\install_autostart.ps1
```

Будет создана задача `Avito Rental Monitor`, запускающаяся при входе пользователя.
Скрипт [`start_parser.cmd`](deploy/windows/start_parser.cmd) ведёт журнал в
`runtime/collector.log` и перезапускает процесс через минуту после падения.

## Данные

- `output/essentuki_rentals.sqlite3` — база и история;
- `output/essentuki_rentals.csv` — все найденные объявления;
- `output/essentuki_candidates.csv` — прошедшие жёсткие фильтры;
- `output/photos/` — фотографии детальных карточек;
- `runtime/` — профиль Chrome, журнал и служебное состояние.

Эти каталоги, `.env` и локальное виртуальное окружение исключены из Git.
